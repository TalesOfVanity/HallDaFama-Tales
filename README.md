# As Crônicas — site do RPG

Estrutura estática pronta para GitHub Pages.

## Arquivos
- `index.html` — Homepage / O Livro
- `hall.html` — Hall da Fama e catálogo das 12 insígnias
- `ranking.html` — Ranking, Renome, Legado e Dragão/MVP
- `css/style.css` — identidade visual e responsividade
- `js/main.js` — menu mobile
- `js/hall.js` — dados das insígnias e Hall da Fama
- `js/ranking.js` — dados e interações do ranking
- `assets/badges/` — ícones enviados

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos mantendo as pastas.
3. Vá em Settings > Pages.
4. Em Source, escolha `Deploy from a branch`.
5. Selecione `main` e `/ (root)`.
6. Salve e aguarde o GitHub Pages publicar.

Os 3 jogadores são dados de teste e podem ser alterados no arquivo `js/ranking.js`.
As 12 insígnias e seus nomes podem ser alterados em `js/hall.js`.
